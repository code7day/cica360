## 2026-08-31 — `Testimonials.astro`: drag/swipe real con Pointer Events (mouse+touch+pen) + dots con el mismo estilo que `Hero.astro`
- **Agente/autor:** Claude
- **Qué se hizo:** el Tech Lead pidió específicamente "cambiar siguiente/anterior con touch o drag and drop" — el scroll-snap nativo daba swipe táctil gratis en teléfonos reales, pero NO daba drag con mouse en desktop (`overflow-x-auto` no se arrastra con el mouse por defecto en ningún navegador). Se agregó un drag handler propio con **Pointer Events** (`pointerdown`/`pointermove`/`pointerup`/`pointercancel`), que unifica mouse+touch+pen en la misma API — durante el drag, `scrollLeft` se mueve 1:1 con el puntero (asignación directa, instantánea, no afectada por `scroll-behavior: smooth`); al soltar, un `nearestIndex()` nuevo calcula qué testimonio quedó más cerca del borde izquierdo y hace `scrollToIndex()` (ese sí animado) para asentar ahí. Se sacó el listener de `touchstart` que quedó redundante (el drag por Pointer Events ya cubre touch). De paso, el Tech Lead compartió una captura de referencia: los dots ahora usan EXACTAMENTE el mismo estilo que los de `Hero.astro` (`bg-white/50` inactivo, `bg-cicagold-500` + se ensancha a `w-6` el activo) — antes eran blancos on/off, sin relación visual con el resto del sitio.

## 2026-08-20 — Segundo `npm run build` real: warning de deprecación y error de TLS local corregidos

Si en el futuro se agrega otro entorno con TLS no confiable, extender ese mismo `if`, no reemplazarlo por algo más permisivo.
